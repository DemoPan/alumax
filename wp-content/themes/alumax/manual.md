# ALUMAX 主题网站内容更新维护操作手册

本手册面向网站内容维护人员，说明如何更新和维护使用 **alumax 主题**（`wp-content/themes/alumax/`）的网站内容。

- 站点环境：WordPress（本地由 WordPress Studio 管理，数据库为 SQLite）
- 后台入口：站点地址后加 `/wp-admin/`（本地地址用 `studio status` 查看）

---

## 一、页面与模板对应关系

alumax 是一个经典 PHP 模板主题，每个页面由主题目录下固定的模板文件渲染。**路径判断模板，内容判断来源**——日常维护改的是「内容来源」列，模板文件只在需要改版式结构时才动。

| 页面 | 前台地址 | 模板文件 | 内容来源 / 维护方式 |
|---|---|---|---|
| 首页 | `/` | `front-page.php` | 后台「首页设置」+ 产品/案例文章（卡片自动读取） |
| 产品中心列表 | `/products/` | `archive-product.php` | 「产品」文章（每页 11 个） |
| 产品详情 | `/products/文章别名/` | `single-product.php` | 统一模块化渲染（见 3.3），模块开关和内容都在后台编辑 |
| 案例列表 | `/projects/` | `archive-case.php` | 「案例」（Projects）文章 |
| 案例详情 | `/projects/文章别名/` | `single-case.php` | 案例文章 + 编辑页案例详情面板（按前端 5 模块排序 + 附录面板） |
| 新闻中心 | `/news/` | `archive-news.php` | 「新闻」文章 + 「新闻 → 新闻页设置」 |
| 新闻详情 | `/news/文章别名/` | `single-news.php` | 新闻文章正文、特色图、分类/标签 |
| 关于我们 | `/about/` | `page-about.php` | 后台「关于我们设置」（见 6.1） |
| 联系我们 | `/contact/` | `page-contact.php` | 后台「联系我们设置」（见 6.2），表单复用产品页公共询价表单 |
| 资料下载 | `/resources/` | `page-resources.php` | 内容写死在模板里，需改代码 |
| 智能百叶（产品详情页示例） | `/products/smart-louver-system/` | `single-product.php` | 模块化渲染（见 3.3），模块开关与内容均在后台编辑 |
| 博客列表（原生文章，未启用） | — | `home.php` | WordPress 原生「文章」，与「新闻」互不影响 |
| 博客详情（原生文章，未启用） | — | `single.php` | 同上 |
| 兜底模板 | — | `index.php` | 以上模板都不匹配时使用，一般无需维护 |
| 页头 / 导航 / 产品下拉菜单 | 全站 | `header.php` | 写死，需改代码 |
| 页脚 | 全站 | `footer.php` | 写死，需改代码 |

模板机制要点：

- **页面模板**：`page-{别名}.php` 自动作用于该别名的页面（如 `page-about.php` ↔ 别名 `about` 的页面）。about / contact / resources 三个页面由主题自动创建，不要删除或改别名，否则模板失效。
- **产品详情分发器**（`single-product.php`）：先按文章别名找 `product-pages/{别名}.php`；找不到时，若该产品绑定了**内容档案**（post meta `_alumax_pp_profile`，见 3.3.1）则直接按模块化新版渲染；都没有才回退通用模板。模块化产品改别名不会丢版式。
- 列表页（产品中心、案例、新闻）和首页卡片都实时读取文章，发文章即出卡片，无需额外配置。

## 二、首页内容维护

后台左侧菜单 **「首页设置」**（房子图标），每一项对应首页一个模块，**留空则显示默认文案**，保存即生效，无需其他操作。

### 2.1 Hero 首屏

- 徽章文字、主标题、副标题
- **整屏链接地址**：填写后点击 Hero 区域任意位置即跳转到该页面（站内路径如 `/products/` 或完整 URL）；留空则不启用链接。轮播切换按钮和播放控制不受影响，点击它们不会跳转

### 2.2 Hero 指标卡（4 组）

- 每组 = 数值（如 `1,200+`）+ 说明（如 `Landmark Installations`）

### 2.3 Hero 轮播（3 张）

- 每张：图片（点「选择图片」从媒体库上传/选择）、标题、副标题

### 2.4 Section 2–5 各板块标题

- 每个板块可改：眉标（小标签）、标题、副标题（Section 5 地标案例无副标题）
- 板块对应：S2 表面处理 / S3 产品展示 / S4 制造能力 / S5 地标案例
- Section 4 额外可改：板块背景图

### 2.5 Section 2 表面处理卡片（5 张）

- 每张：背景图（媒体库选择）、标签、标题、描述、底部规格名称 + 规格值

### 2.6 Section 4 制造能力指标与工艺卡片

- **指标条（5 项）**：每项 = 数值（如 `±0.3mm`）+ 说明
- **工艺卡片（6 张）**：每张 = 图标（[Material Symbols](https://fonts.google.com/icons) 图标名，如 `precision_manufacturing`）、标题、描述、底部规格名称 + 规格值

### 2.7 首页上的卡片（不需要在首页设置里改）

- **产品卡片（Section 3）**：自动读取「产品」文章，按发布时间排序，第一篇为主推大卡
- **案例卡片（Section 5）**：自动读取「案例」文章
- 想换卡片内容 → 去改对应的文章（标题、摘要、特色图）

## 三、产品维护

### 3.1 新增一个产品

1. 后台 **「产品 → 新建」**
2. 填写：
   - **标题**：产品名（显示在卡片和详情页）
   - **别名（slug）**：英文小写短横线格式，如 `acoustic-louver-system`。**别名决定详情页用哪个专属模板，见 3.3**
   - **摘要**：显示在首页/产品中心卡片上的简介；**不填则显示正文全文（不截断）**
   - **特色图片**：卡片配图
   - **产品分类**（右侧边栏）：勾选所属分类，决定产品中心分类标签下的归属（见 3.5）
   - **产品特性面板**（编辑页下方）：逐行添加「特性名称 + 数值」，如 `Max Single Sheet` / `2,200mm × 6,000mm`。数量不限，普通卡片只显示前几条，主推大卡全部显示；这些文本同时用于产品中心参数下拉筛选（见 3.5）
3. 发布。卡片自动出现在首页 Section 3 和产品中心列表页

### 3.2 修改 / 下架产品

- 修改：「产品」列表里点编辑，改完更新即可
- 下架：把文章改为「草稿」或删除，卡片随之消失

### 3.3 产品详情页：统一模块化渲染

`single-product.php` 不再是分发器：**所有产品详情页统一由 `alumax_render_product_page()` 模块化渲染**（旧通用模板和 `product-pages/` 专属模板目录已废弃删除）。

每个产品启用哪些模块，在后台 **「产品 → 编辑」右侧「详情页模块」面板**勾选（存 post meta `_alumax_pp_modules`）：

- 默认勾选：首屏 Hero、产品介绍、核心优势、技术参数、产品细节、安装方式、工程案例、询价表单
- 默认不勾选：产品特殊属性（如电机与智能控制系统）、涂层结构与颜色
- 勾选了但内容为空的模块自动跳过；取消勾选则前台整模块不渲染

**新增产品**：直接「产品 → 新建」，写完标题保存即是模块化详情页（Hero 自动取文章标题和特色图，询价表单用通用文案）；要改内容就在同页 4 个「详情页内容」面板里编辑，要开关模块就在「详情页模块」勾选。**不需要再新建模板文件**。

11 个现有产品的模块勾选已按当前页面效果固化（参数配置器含特殊属性模块，其余不含）。

#### 3.3.1 模块化产品详情页（内容与默认文案）

模块化详情页由 `template-parts/product-sections/` 下的 10 个可复用 section 组件拼装，渲染顺序固定（由 `alumax_render_product_page()` 统一维护，无内容的模块自动跳过）：

1. **hero**（首屏，深色，面包屑内嵌顶部）
2. **intro**（产品介绍：干嘛的、用在哪、解决什么问题）
3. **advantages**（核心优势）
4. **control**（产品特殊属性，可选——名称按产品定，如智能百叶的「电机与智能控制系统」；目前仅 system-parameter-configurator 启用）
5. **specs**（技术参数：规格表 + 右侧技术图卡）
6. **palette**（涂层结构与颜色，白底）
7. **options**（产品细节：节点/工艺/定制卡片）
8. **install**（安装方式：安装节点卡，白底；卷材类产品可改为「出口包装与交付」）
9. **cases**（工程案例，浅灰底）
10. **inquiry**（询价表单，深色）

**内容在后台编辑**：打开「产品 → 所有产品 → 编辑」，页面下方会出现 4 个「详情页内容」面板（Hero+产品介绍 / 核心优势+智能控制+定制选项 / 技术参数+安装方式 / 工程案例+询价表单），所有文案、图片、规格表行、卡片都可在面板里增删改，图片支持媒体库选择。保存前页面显示主题内置的默认内容（定义在 `inc/product-page-content.php` 的 `alumax_product_page_defaults()`）。

技术说明：

- 数据按 section 存为 post meta（`alumax_pp_{section}`），前台由 `alumax_product_page_sections()` 组装；安装方式模块的数据存放在 specs meta 的 `install_*` 键中（历史原因，后台字段在「技术参数」面板底部）
- **内容档案与别名解耦**：11 个现有产品存有 `_alumax_pp_profile` 档案键，默认内容（`alumax_product_page_defaults()`）按档案键分发；改文章别名不影响版式和内容。新建产品无档案键，使用通用默认内容（空内容模块不渲染），无需注册
- 规格表的「等宽」列填 1 时数值用等宽字体；产品细节卡的「线图模式」填 1 时图片完整显示不裁切；产品细节卡、安装节点卡和技术参数侧卡均支持直接粘贴 SVG 代码（线图/示意图，`alumax_pp_kses_svg` 白名单过滤）；卡片图片和 SVG 都留空时媒体区域自动隐藏
- 面包屑内嵌在 hero 组件顶部（`template-parts/product-breadcrumb.php` 的 `hero` 深色变体）；不启用 Hero 模块时产品页无面包屑。列表页仍用浅色条变体
- 询价表单：前端 fetch 异步提交到 REST 接口 `POST /wp-json/alumax/v1/inquiry`（逻辑在 `inc/inquiries.php`），数据存入私有文章类型 `inquiry`，后台一级菜单 **「询价记录」** 查看（列表含姓名/邮箱/意向产品/来源页/附件列，详情页只读展示全部字段与留言；意向产品字段已从表单移除，新记录该列为空，旧记录保留历史值）。校验：姓名必填 + 邮箱格式（前端即时标红提示 + 服务端二次校验）、蜜罐防机器人；附件限 .DWG/.DXF/.RVT/.PDF/.ZIP ≤25MB，存至媒体库目录；提交后页面内直接显示成功/失败横幅，不跳转；无 JS 时回退为 admin-post 提交（nonce 防跨站），跳回产品页锚点 `#rfq-section`

### 3.4 产品中心列表页说明

- 地址 `/products/`，每页 11 个产品
- 内容全部来自「产品」文章，无单独设置项

### 3.5 产品分类与筛选联动

- 后台 **「产品 → 产品分类」** 可增删改分类；编辑产品时勾选所属分类
- 产品中心的分类标签按钮（All Systems / Exterior Cladding 等）由分类自动生成，括号内为真实产品数；未分类的产品只出现在 All Systems 下
- 下方 4 个参数下拉框（Fire Rating / Alloy Grade / Surface Coating / Panel Caliber）与每个产品的**「产品特性」字段文本**匹配，例如某产品特性值含 `A1`，选择 Fire Rating 的 A1 选项时该产品会保留
- 右上角视图切换：网格 / 列表（列表模式地址为 `/products/?view=list`，所有卡片复用主推卡样式，仅第一张显示 FEATURED 徽章）
- 已内置 4 个分类：Exterior Cladding、Solar & Shading、Insulated & Composites、Ceilings & Screens，可自行改名或新增

## 四、案例（Projects）维护

### 4.1 新增一个案例

1. 后台 **「Projects → 新建」**
2. 基础字段：
   - **标题**：项目名
   - **正文**：项目介绍，显示在详情页 02 Overview 板块
   - **摘要**：详情页 Hero 段落；留空时自动截取正文
   - **特色图片**：详情页 Hero 背景、列表卡片图、Spotlight 大图；图集第 1 组、Challenge 大配图留空时也会回退用它
3. 编辑页下方的案例详情面板**按详情页前端 5 个模块从上到下排列**，另有一个附录面板；全部支持增删行，未保存过的案例会显示一套 KAFD 示例默认值：

**01 Hero：页头信息 + Project Snapshot + Key Metrics**

- 页头：档案编号 REF（如 `#ALX-GCC-2024-K3`）、地点（如 `RIYADH, KSA`，也用于卡片角标）、竣工状态（如 `COMPLETED 2024`）、认证徽章（如 `LEED PLATINUM & CWCT`，列表页 Spotlight 按 `&` 拆成多个徽章）、卡片标签（显示在详情页 Hero meta 行、列表卡片角标和 Spotlight 底条）
- Project Snapshot：属性名 + 内容 + 副行备注（可选），逐行增删；用于 Hero 右侧 Snapshot 卡（前 5 行）和 02 Overview 属性瓦片；**全部删除后这两处前台隐藏**
- Key Metrics：名称 + 数值 + 说明 + 图标，默认 4 项；图标填 Material Symbols 名称（如 `aspect_ratio`、`thermostat`、`air`、`shield`），留空按顺序取默认图标。用于 Hero 底部 4 格、列表页 Spotlight 3 格（前 3 项）和列表卡片规格行（前 4 项）

**02 Project Overview**

- 仅一个字段：Overview 标题（留空时使用文章标题）
- 该板块其余内容无需在面板编辑：正文段落取自文章编辑器内容，属性瓦片取自 01 面板的 Project Snapshot

**03 Project Challenge**

- 标题、正文（留空时不显示该段落）、左侧大配图（留空用特色图片）及配图角标/标题/描述、细节小图（留空用图集第 2 组图片）及小图角标/标题
- 挑战条目卡片：标题 + 内容，可增删，前台自动按 01 / 02 / 03 编号

**04 Project Gallery（图集）**

- 固定 4 组：第 1 组为大图（留空用特色图片），每组含图片 / 标签 / 标题 / 描述；前台按 8 / 4 / 6 / 6 栅格拼版，标签显示为「序号 // 标签」

**05 Related Products**

- 自动读取最新发布的 3 个「产品」文章，无需编辑

**附：Spotlight 数据与保留字段（详情页不渲染）**

- Verification Metrics：参数 / 设计要求 / 交付测试结果 / 参考标准，逐行增删；前 6 行用于项目中心页 Spotlight 规格表
- 下载资料：图标、文件信息（如 `DWG // 8.4 MB`）、标题、描述、下载链接、按钮文案；第一个有效链接（非 `#`）显示为 Spotlight 的 BIM 下载按钮
- Material Substrates：当前前端模板未使用，数据保留备查；规格每行一条，格式为 `名称|数值`（注意中间是英文竖线）

### 4.2 案例列表页

- 地址 `/projects/`，无单独设置项
- 结构：深色 Hero（含站点级指标条）→ 规格筛选条（4 个下拉 + 网格/列表切换，纯前端按卡片文本匹配，无需配置）→ Spotlight（自动取最新一篇案例，仅第 1 页显示，读取其页头字段、指标前 3 项、Verification 前 6 行、Challenge 正文和首个有效下载链接）→ 案例卡片网格（每页 9 张，卡片读取页头字段 + 指标前 4 项）→ 真实分页
- 卡片右上角年份自动从「竣工状态」中提取 4 位数字，提取不到时用发布年份

### 4.3 案例详情页

- 地址 `/projects/文章别名/`，模板 `single-case.php`，板块顺序固定：Hero（背景=特色图，含面包屑 / Snapshot 卡 / 指标 4 格）→ 02 Project Overview（Overview 标题 + 正文 + Snapshot 属性瓦片）→ 03 Project Challenge（双图 + 编号卡片）→ 04 Project Gallery（4 张拼版）→ 05 Related Products（自动取最新 3 个产品）
- 详情页不含询价表单
- 面包屑与产品页共用 `template-parts/product-breadcrumb.php`（hero 深色变体，`archive_label` 传 `Projects`、`archive_url` 传案例归档链接；列表页再传 `current => ''` 显示二级）

## 五、新闻维护

### 5.1 发布一篇新闻

后台 **「新闻 → 新建」**，填写：

- **标题**
- **正文**：详情页正文，支持小标题 / 图片 / 引用，模板自动排版
- **摘要**：显示在列表卡片上；不填自动截取正文
- **特色图片**：列表卡片图 + 详情页顶部大图；特色图的「说明文字」会显示为详情页大图图注
- **作者**：详情页署名

可选字段：

- **新闻分类**：列表页顶部筛选 tab + 卡片左上徽章（JS 只筛选当前页）
- **新闻标签**：列表视图卡片上的规格小 chips（如 `Alloy: AA5052-H32`）
- **自定义字段 `location`**：卡片右下/列表行的地点徽章（如 `Riyadh, KSA`）。在文章编辑页打开「自定义字段」面板添加

### 5.2 新闻页设置（轮播 / 列表区标题 / 订阅板块）

后台 **「新闻 → 新闻页设置」**，分三组：

**顶部轮播（3 张 Banner）**，每张可设：

- Banner 图片（媒体库选择）
- 底部标签短标题、顶部眉标、分类徽章、标题、描述、地点/展位行
- 「链接到新闻文章」下拉：选择点击 View Details 跳转的新闻；不选则按钮不可点击
- **标题留空的轮播不显示**；全部未配置时显示默认示例

**列表区标题**：新闻卡片列表上方的眉标和标题。

**底部订阅板块**：标题、描述、按钮文案、表单下方备注；**标题留空则整个板块不显示**。访客提交邮箱后写入「询价记录」（来源页标记为 Newsletter Signup）。

### 5.3 新闻中心列表页功能

- 地址 `/news/`，每页 6 篇，底部分页
- 搜索框 / 年份下拉 / 分类 tab 均为**前端 JS 即时筛选**，三者可叠加，作用于当前页文章；JS 失效时搜索和年份自动回退为服务端筛选（URL 参数 `?news_search=` / `?news_year=`）
- 卡片视图 / 列表视图切换为前端 JS

### 5.4 注意事项

- 如果后台存在别名为 `news` 的**页面**，会与 `/news/` 归档地址冲突，需删除或改别名
- 若 `/news/` 出现 404，到「设置 → 固定链接」直接点一次「保存更改」即可

## 九、本地站点的启动与发布（WordPress Studio）

本站由 WordPress Studio 管理，常用命令（在站点根目录终端执行）：

```bash
studio status            # 查看站点地址、后台账号、PHP/WP 版本
studio start             # 启动本地站点
studio stop              # 停止站点
```

### 备份 / 导出

```bash
studio export backup.zip           # 完整备份：wp-content + 数据库
studio export my-site.sql --mode db  # 仅导出 MySQL 兼容的数据库 dump
```

### 发布到线上（WordPress.com / Pressable）

```bash
studio auth login   # 先登录 WordPress.com 账号（打开浏览器授权）
studio push         # 把本地站点推送到已连接的线上站点（会覆盖线上，先确认）
studio pull         # 把线上站点拉回本地（会覆盖本地，先确认）
```

可用 `--options <all|sqls|uploads|plugins|themes|contents>` 限定同步范围。

## 十、静态导出版本部署（纯 HTML，任意静态托管）

站点可导出为纯静态版本，适合部署到 Netlify / Cloudflare Pages / GitHub Pages / 阿里云 OSS 等静态托管。**WordPress 仍需保持在线**（如 `cms.你的域名`），负责内容管理和接收询价表单；静态站做门面。

### 导出步骤

1. 确保本地站点正在运行（`studio start`）
2. 在站点根目录执行：

```bash
node tools/export-static.cjs                                              # 本地测试（接口指向 localhost）
node tools/export-static.cjs http://localhost:8881 https://cms.example.com  # 正式上线（表单接口指向线上 WP）
```

3. 把生成的 `static-export/` 目录**整体**上传到静态托管（链接为根相对路径，**必须部署在域名根目录**，不能放子路径）

### 静态版功能对照

| 功能 | 静态版表现 |
|---|---|
| 页面浏览、导航、图片 | 完全一致 |
| 询价表单（RFQ） | 正常：fetch 直连线上 WP 的 REST 接口 `/wp-json/alumax/v1/inquiry`，记录照常进后台「询价记录」，页面内横幅提示成功/失败 |
| 新闻搜索 / 年份 / 分类筛选 | 正常：纯前端 JS 即时筛选（当前页范围） |
| 分页（新闻、产品） | 导出时只抓取已渲染的页码；内容增多后需重新导出 |

### 日常更新流程

后台改内容 → 重新执行导出命令 → 重新上传 `static-export/`（或配置自动部署）。

> `static-export/` 已在 `.gitignore` 中排除；导出脚本 `tools/export-static.cjs` 随仓库入库。
> 静态站域名确定后，可在主题里用 `alumax_inquiry_cors_origin` 过滤器把接口跨域来源从 `*` 收紧为指定域名。

## 十一、常见问题

**改了内容前台没变化？**
先确认文章/设置已点「发布/更新/保存更改」；再强制刷新浏览器（Ctrl+F5）。

**新增页面后访问 404？**
到「设置 → 固定链接」点一次「保存更改」，刷新重写规则。

**产品详情页想关掉某个模块？**
到「产品 → 编辑」右侧「详情页模块」取消勾选即可，无需改代码。

**案例详情字段全部乱了想重来？**
案例详情面板保存过就以保存值为准；把对应面板内容清空保存，该模块前台会隐藏（Snapshot 等），或参照 KAFD 示例默认值重新填写。

**需要新增语言、表单邮件通知、SEO 等功能？**
产品页询价表单已支持提交入库（见 3.3），但不会发送邮件通知；多语言、邮件提醒、SEO 等需求需要安装插件或开发，请联系技术人员。
